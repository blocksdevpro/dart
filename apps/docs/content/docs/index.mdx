**Dart** is an ultra-fast, local Fabric Minecraft server instance manager featuring an interactive **Ratatui Terminal UI**, an ergonomic **CLI**, and a modular background **daemon** built with Rust.

<TuiPreview />

## Why Dart?

Running local Minecraft Fabric servers often involves juggling shell scripts, manually downloading Fabric installer JARs, managing Java versions, manually hunting for Modrinth mod dependencies, and handling messy server directories. 

Dart replaces this fragmented workflow with a unified, native toolchain:

## Quick Example

Create a fresh Minecraft 1.21.4 Fabric server with EULA accepted in one line:

```bash
dart create survival "Survival 1.21" --minecraft 1.21.4 --accept-eula
```

Then open Dart's interactive dashboard:

```bash
dart
```

## Architecture at a Glance

Dart is organized into two primary layers:

1. **Frontend Layer (`dart`)**:
   - **CLI Parser** (`src/cli`): Converts argv into strongly typed command enums before performing any disk or network operations.
   - **TUI Dashboard** (`src/tui`): Ratatui-powered terminal user interface with reactive log rendering and tab navigation.
2. **Control & Daemon Layer (`crates/dart-daemon`)**:
   - **Instance Store & Service**: Manages server configs (`dart.toml`), directory creation, and instance states.
   - **Server Supervisor**: Spawns and supervises background Java processes with non-blocking async channels.
   - **Fabric Meta Client**: Queries `meta.fabricmc.net` and caches launcher JARs.
   - **Content Manager**: Manages mods, data packs, and Modrinth integrations.
