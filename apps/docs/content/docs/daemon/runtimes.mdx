## Fabric Meta API Integration

Instead of bundling opaque JAR files or requiring manual installations of the Fabric GUI installer, Dart communicates directly with the official [Fabric Meta API](https://meta.fabricmc.net/):

```text
https://meta.fabricmc.net/v2/versions/
```

### Version Triplets: `FabricRuntime`

A complete Fabric server specification requires three components:

1. **Minecraft Version** (`FabricVersion`): The vanilla game version (e.g., `1.21.4`, `1.20.1`).
2. **Fabric Loader Version** (`FabricVersion`): The mod-loading core (e.g., `0.16.10`).
3. **Fabric Installer Version** (`FabricVersion`): The bootstrapper that bundles libraries (e.g., `1.0.1`).

Together, these form a strongly typed [`FabricRuntime`](file:///home/uttam/dart/crates/dart-daemon/src/runtime/mod.rs#L55).

## Runtime Caching (`RuntimeStore`)

Runtimes are cached centrally under `$DART_HOME/runtimes/fabric/`:

```text
$DART_HOME/runtimes/fabric/
├── 1.21.4-0.16.10-1.0.1/
│   └── fabric-server-launch.jar
├── 1.20.1-0.16.9-1.0.1/
│   └── fabric-server-launch.jar
└── meta-cache.json
```

### Advantages of Centralized Caching

* **Deduplication**: When you create 5 different Minecraft `1.21.4` instances (e.g. Survival, Creative, Minigames), they all reuse the identical cached launcher JAR rather than downloading 200MB 5 times.
* **Offline Boot**: Once a runtime version is downloaded, server instances using that version can be created and launched completely offline without internet connectivity.
* **Atomic Writes**: Downloads are streamed to temporary files (`.tmp`) and verified before renaming, preventing broken or corrupted JAR files if a download is interrupted.

## CLI Runtime Commands

You can manage cached runtimes directly through the CLI:

### List Cached Runtimes
```bash
dart runtimes list
```
Output:
```text
Cached Fabric runtimes in ~/.local/share/dart/runtimes/fabric:
  - Minecraft 1.21.4, Loader 0.16.10, Installer 1.0.1
  - Minecraft 1.20.1, Loader 0.16.9,  Installer 1.0.1
```

### Pre-cache a Runtime
You can download a launcher ahead of time without creating an instance:

```bash
# Downloads the latest stable Fabric runtime for 1.21.4
dart runtimes download 1.21.4

# Downloads the newest release of Minecraft
dart runtimes download
```
