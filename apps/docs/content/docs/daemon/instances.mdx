In Dart, an **Instance** is an isolated Minecraft Fabric server directory with its own world files, configuration, installed mods, and server properties.

---

## Instance Identity: `InstanceId`

Every instance is uniquely referenced by an [`InstanceId`](file:///home/uttam/dart/crates/dart-daemon/src/instance/mod.rs#L40).

### Validation Rules
* **Length**: Between 1 and 64 characters.
* **Allowed Characters**: Lowercase ASCII alphanumeric (`a-z`, `0-9`) and hyphens (`-`).
* **Boundary Rules**: Must start and end with an alphanumeric character (cannot begin or end with a hyphen).

Valid examples:
* `survival-121`
* `test-server`
* `smp`

Invalid examples:
* `-server` *(starts with hyphen)*
* `MyServer` *(contains uppercase)*
* `server_world` *(contains underscore)*

## Configuration File: `dart.toml`

Each instance directory stores its metadata and launch configuration in `instances/<id>/dart.toml`.

Dart uses **Config Format Version 2**:

```toml
# ~/.local/share/dart/instances/survival/dart.toml
version = 2
name = "Survival SMP"

[runtime]
minecraft = "1.21.4"
loader = "0.16.10"
installer = "1.0.1"

[java]
command = "java"
args = ["-Xms2048M", "-Xmx4096M", "-XX:+UseG1GC"]
memory_mb = 4096

[eula]
accepted = true
```

### Configuration Fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `version` | `u32` | Configuration format version (currently `2`). |
| `name` | `String` | Human-readable server name (1-64 chars, no newlines). |
| `runtime.minecraft` | `String` | Target Minecraft release or snapshot version. |
| `runtime.loader` | `String` | Fabric Loader version. |
| `runtime.installer` | `String` | Fabric installer version used to assemble launcher JAR. |
| `java.command` | `String` | Path or name of the Java executable (defaults to `java`). |
| `java.args` | `Vec<String>`| JVM launch flags. |
| `java.memory_mb` | `u32` | Maximum heap allocation limit in megabytes. |
| `eula.accepted` | `bool` | Whether the Minecraft EULA has been accepted. |

## Lifecycle State Machine

The daemon tracks every instance through a strict finite state machine defined by [`InstanceState`](file:///home/uttam/dart/crates/dart-daemon/src/instance/mod.rs#L250):

```mermaid
stateDiagram-v2
    [*] --> Stopped
    Stopped --> Starting: Supervisor::Start(instance)
    Starting --> Running: Child process spawned with PID
    Running --> Stopping: Supervisor::Stop(instance) / "stop"
    Stopping --> Stopped: Process exits with status 0
    Starting --> Failed: Java not found or launch error
    Running --> Failed: Unexpected exit / crash
    Failed --> Stopped: Acknowledged / Cleaned up
```

### States

1. **`Stopped`**: The instance is idle. No Java process is active.
2. **`Starting`**: The daemon has assembled the runtime arguments, verified EULA, and invoked the OS process spawn.
3. **`Running { pid: u32 }`**: The Minecraft server process is active. The OS process ID is exposed for diagnostics and monitoring.
4. **`Stopping`**: A graceful shutdown command has been dispatched via standard input (`stop\n`). The supervisor waits for clean world saves.
5. **`Failed { message: String }`**: The server crashed, was killed by an external signal, or failed to launch. The error message contains diagnostic details.

## EULA Acceptance (`EulaAcceptance`)

Minecraft servers require explicit agreement to Mojang's End User License Agreement before the server process will load the world.

When creating an instance:
* If `--accept-eula` is passed, Dart writes `eula=true` directly to `eula.txt` in the instance directory.
* If omitted, Dart prompts during first boot or marks the instance with `EulaAcceptance::NotAccepted`.
