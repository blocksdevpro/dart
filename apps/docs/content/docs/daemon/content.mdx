---

## Content Categories: `ContentKind`

Dart divides installable add-on content into three distinct types:

| Kind | Target Directory / Destination | Description |
| :--- | :--- | :--- |
| **`ContentKind::Mod`** | `<instance>/mods/*.jar` | Fabric server-side mods (e.g., Fabric API, Lithium, FerriteCore, Chunky). |
| **`ContentKind::DataPack`** | `<instance>/<world>/datapacks/*.zip` | In-game data packs altering loot tables, recipes, structures, or dimensions. |
| **`ContentKind::ResourcePack`** | Configured in `server.properties` | Server-enforced resource packs for custom models, textures, or audio. |

## Modrinth API v2 Integration

Dart includes a built-in async HTTP client for the [Modrinth API](https://docs.modrinth.com/):

```text
https://api.modrinth.com/v2/
```

### Search & Filtering
When searching for content:
* Filters results automatically by **Fabric** loader compatibility.
* Restricts versions to the instance's configured **Minecraft version**.
* Respects client-side vs. server-side environment requirements (`required`, `optional`, `unsupported`).

```rust
let results = daemon
    .search_mods("lithium", &instance)
    .await?;

for hit in results {
    println!("Found mod: {} (Downloads: {})", hit.title, hit.downloads);
}
```

## Cryptographic Hash Verification

Security is a primary concern when automating third-party mod downloads. To prevent man-in-the-middle tampering, incomplete downloads, or mirror corruptions, Dart's `ContentManager` verifies cryptographic hashes on every downloaded file:

<Callout type="warn" title="Strict Integrity Check">
  Every file fetched from Modrinth is validated against its published **SHA-1** and **SHA-512** digests before being moved into the instance directory. If any hash fails to match, Dart immediately aborts the installation and cleans up temporary files.
</Callout>

```text
Download Stream ──> Temp File ──> Calculate SHA-512 ──> Match API Hash?
                                                               │
                                         ┌─────────────────────┴─────────────────────┐
                                      [Match]                                    [Mismatch]
                                         │                                           │
                           Move to instances/<id>/mods/                       Delete Temp File
                                                                            & Raise ContentError
```

## Modpack Support (`.mrpack`)

Dart natively handles Modrinth modpack archives (`.mrpack` files):
1. **Reads `modrinth.index.json`**: Inspects modpack metadata, dependencies, and file list.
2. **Generates an Install Plan** (`ContentInstallPlan`): Calculates all necessary files, required versions, and overrides.
3. **Parallel Fetching**: Downloads required server-side mods concurrently with SHA validation.
4. **Applies Overrides**: Unpacks server configuration overrides directly into the instance directory.
