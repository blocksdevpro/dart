Dart features a full-screen, high-performance Terminal User Interface powered by [Ratatui](https://github.com/ratatui/ratatui) and [Crossterm](https://github.com/crossterm-rs/crossterm).

Launch the TUI at any time:
```bash
dart
```

## Interface Layout

The Dart TUI is divided into three primary zones:

1. **Instance Sidebar (Left Pane)**:
   * Displays all detected instances in `$DART_HOME/instances`.
   * Highlights current lifecycle state (`RUNNING`, `STOPPED`, `STARTING`, or `FAILED`).
   * Displays Minecraft and Fabric loader versions for quick reference.

2. **Main Viewport (Right Pane)**:
   * **Instance Header**: Displays the active server's ID, allocated RAM, port, and EULA status.
   * **Live Console View**: Streams standard output and error logs in real time as emitted by the underlying Java process.
   * **Mod Browser**: Allows inspecting installed mods and Modrinth dependencies.

3. **Global Status Bar (Footer)**:
   * Shows active keybindings, daemon connection status, and background process health.

## Keyboard Controls & Shortcuts

Dart is designed for swift, keyboard-first navigation:

| Key | Action | Description |
| :--- | :--- | :--- |
| <kbd>↑</kbd> / <kbd>↓</kbd> | **Select Instance** | Move up and down through the list of servers in the sidebar. |
| <kbd>Enter</kbd> or <kbd>s</kbd> | **Start / Stop** | Boot the selected server, or begin a graceful shutdown. |
| <kbd>Tab</kbd> | **Switch Panes** | Cycle focus between the sidebar, console viewport, and tabs. |
| <kbd>m</kbd> | **Mod Browser** | Open the mod manager tab to inspect installed JARs. |
| <kbd>PageUp</kbd> / <kbd>PageDown</kbd> | **Scroll Console** | Scroll through earlier server log lines. |
| <kbd>c</kbd> | **Clear Logs** | Clear the in-memory display buffer for the current session. |
| <kbd>q</kbd> or <kbd>Ctrl+C</kbd> | **Quit TUI** | Exit Dart. Running server instances remain active in the background! |

---

## Background Persistence

When you exit the TUI by pressing <kbd>q</kbd>, any running Minecraft server processes **continue running smoothly in the background**. 

When you re-open Dart later with `dart`, the TUI instantly reconnects to the existing daemon supervisor, reconnects to the live log streams, and displays the current state.
